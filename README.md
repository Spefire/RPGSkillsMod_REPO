# RPG Skills Mod

Adds RPG classes to R.E.P.O., each with 2 unique active skills.

![Status](https://img.shields.io/badge/Status-Testing-orange)
![Version](https://img.shields.io/badge/Version-2.0.1-blue)

## Features

- 5 classes, each with 2 active skills and an in-game cooldown HUD
- Class selection in the shop and lobby, saved per save file
- Configurable keybinds: `F` / `R` use the skills, `F6` / `F8` change class, `H` shows/hides the HUD (see the BepInEx config)
- Multiplayer: skills with a world effect go through the host, so **the host must have the mod**

## Installation

Install **RPGSkillsMod** from [Thunderstore](https://thunderstore.io/c/repo/p/Spefire/RPGSkillsMod/) with your mod manager; BepInEx is installed automatically as a dependency.

## Classes & Skills

| Class | Skills |
|---|---|
| **Warrior** | Berserk, Predator Sense |
| **Paladin** | Divine Taunt, Shockwave |
| **Scout** | Best Runner, Treasure Sense |
| **Druid** | Nature's Blessing, Raise Dead |
| **Mage** | Phantom, Reinforce |

Full effect descriptions, cooldowns, radius and durations for every skill are on the **[Wiki](https://thunderstore.io/c/repo/p/Spefire/RPGSkillsMod/wiki)**.
