# Classes & Skills

Each class has **2 independent active skills**, each with its own cooldown.
Use the **primary skill key** (default `F`) for the first skill and the
**secondary skill key** (default `G`) for the second. Cooldowns and
readiness are shown on the in-level HUD.

| Class | Skill | Slot | Effect | Cooldown | Status |
|---|---|---|---|---|---|
| [Warrior](Warrior.md) | Berserk | Primary | Increases your strength. | 90s | ✅ OK |
| [Warrior](Warrior.md) | Predator Sense | Secondary | Marks nearby enemies on the map, revealing them to every player. | 60s | ✅ OK |
| [Paladin](Paladin.md) | Divine Taunt | Primary | Grants invulnerability, but forces nearby enemies to focus you. | 60s | ✅ OK |
| [Paladin](Paladin.md) | Shockwave | Secondary | Releases a powerful shockwave, stunning all nearby enemies. | 75s | ✅ OK |
| [Scout](Scout.md) | Best Runner | Primary | Grants infinite stamina. | 60s | ✅ OK |
| [Scout](Scout.md) | Treasure Sense | Secondary | Reveals valuable items around you. | 60s | ✅ OK |
| [Druid](Druid.md) | Nature's Blessing | Primary | Heal nearby allies within a small radius. | 45s | ✅ OK |
| [Druid](Druid.md) | Raise Dead | Secondary | Sacrifice your own health to revive yourself, or a fallen ally. | 120s | 🧪 Testing |
| [Mage](Mage.md) | Phantom | Primary | Become undetectable by enemies, floating like a ghost. | 60s | ✅ OK |
| [Mage](Mage.md) | Reinforce | Secondary | Makes the item you're currently holding unbreakable. | 90s | ✅ OK |

See each class's page for exact radii, durations and other properties.
